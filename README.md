# Impostor_Syndrome_LinkedIn

##### This project analyzes the prevalence of impostor syndrome across various professional and educational populations using survey and research data collected from multiple studies. The goal was to identify which populations were most frequently studied, determine prevalence trends, and communicate findings through interactive visualizations.

### Objectives
- Clean and prepare a raw dataset for analysis
- Explore prevalence patterns across populations and geographic locations
- Identify the most commonly studied populations in the United States
- Calculate prevalence metrics and sample distributions
- Create visualizations that clearly communicate key findings
